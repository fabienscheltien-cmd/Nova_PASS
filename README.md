# Nova Pass

je veux créer un otils de ticketting pour un accueil d entreprise. Je veux que quand une personne arrive a l accueil, on lui présente un QR code. Une fois le QR code prise en phot, ca ouvre une page d 'identification de la personne qui vient sur site avec Nom prenom Entrprise date heure, personne visitée et entreprise visitée. Ensuite une fois validé ca enregistre les informations sur un registre. Ensuite un mail est envoyé a l acuueil avec toutes les informations, et ensuite l hotessse d eccaueil peut laisser entrer la personne. Cest informations seront accessibles avec la possibilité de faire un export sur excel. Il faudra des filtres en ligne pour choisir des dates . Dis moi si tu as des questions ou des suggestions
